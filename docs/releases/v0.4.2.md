# PATH v0.4.2

## Scope

PATH v0.4.2 adds an in-repository exact-artifact preview and a versioned,
address-free downstream integration bundle. It does not change contract source,
ABI, creation bytecode, runtime bytecode, issuance behavior, Spark behavior,
movement authorization, metadata, or token artwork from v0.4.1.

## Exact-artifact preview

`evm/preview/index.html` displays eight movement states generated from an
ephemeral Hardhat deployment. Tokens are issued through the canonical
`PulseAuction -> PathPulseAdapter -> PathNFT` path and the page renders the
embedded `PathNFT.tokenURI` image directly.

The page supports search, stage filtering, gallery/grid/thumbnail scales,
artifact detail, trait inspection, hashes, and SVG download. It has no RPC,
wallet, webfont, or external renderer dependency.

## Downstream artifacts

The public bundle at `releases/v0.4.2/` contains:

- ABI-only JSON for `PathNFT`, `PathPulseAdapter`, and `PulseAuction`;
- full Hardhat artifacts for those three canonical contracts;
- compiler settings, source pin, byte sizes, and bytecode hashes;
- a downstream implementation handoff;
- machine-readable and `sha256sum`-compatible checksums.

Network addresses are deliberately excluded. Sepolia and Mainnet consumers
must pair these interface artifacts with a separately verified deployment
release for that chain.

## Compatibility

- Contract source and bytecode: unchanged from v0.4.1.
- ABI: unchanged from v0.4.1.
- PATH Hardhat runtime template hash:
  `0x8f8bdfadd6c6ea22d55193e8c4d6166e3f3728bc8a17ae84137588317b972a0a`.
- Exact-preview deployed runtime hash:
  `0xf547ec0b9305d626df2c6afd3dd876623bceb5baf6bd6d35102da23495ad4dd6`.
  This concrete hash includes constructor immutables and is not an expected
  network deployment hash.
- Stable traits remain `Stage`, `THOUGHT`, `WILL`, and `AWA`.
- Spark remains detectable through `PathNFT.isSparker(tokenId)` and is not a
  metadata trait.
- No redeployment is required solely for this release.
