# PATH v0.4.1

## Scope

PATH v0.4.1 hardens the canonical on-chain token artwork without changing the
public ABI, Spark claim flow, movement authorization, metadata traits, or Pulse
issuance path.

## Token artwork

- The image remains a centered `THOUGHT WILL AWA` line on a `600x600` black
  canvas.
- Remaining progress is `#ffffff`; consumed progress is `#00ff35`.
- Each movement fills left-to-right using its own minted/quota ratio.
- The renderer embeds only `T`, `H`, `O`, `U`, `G`, `W`, `I`, `L`, and `A`.
- No TTF, WOFF, browser font, off-chain renderer, or shared on-chain font
  contract is required.

The glyph subset is pinned in
`evm/glyphs/inshell-mono-76-path-400.json`. The generated Solidity library is
`evm/src/InshellMono76PathGlyphs.sol`. Compile and test entrypoints run
`npm run glyphs:check` first and reject generated-source drift.

The SVG root publishes the Inshell Mono 76 release commit, package manifest
SHA-256, glyph JSON SHA-256, and PATH subset SHA-256 for downstream provenance.

## Release evidence

- Solidity compiler: `0.8.24`, optimizer `200`, `viaIR=true`.
- Full tests: `86/86` passing.
- `PathNFT` runtime: `21,936` bytes.
- EIP-170 headroom: `2,640` bytes.
- Local deployment used Spark reserved cap `99` and claim duration `604800`.
- Local smoke mint passed through `PulseAuction -> PathPulseAdapter -> PathNFT`.
- Gallery generated 13 states for movement quotas `1 / 10 / 1` through the
  same canonical public issuance path.
- Desktop and mobile rendering loaded all 13 SVG images; mobile body overflow
  was zero.

## Downstream compatibility

The ABI is unchanged from v0.4.0, but the `PathNFT` runtime bytecode and
on-chain SVG provenance attributes changed. Downstream repositories should
import the v0.4.1 artifact set as one release and must not combine a v0.4.0
address/code hash with v0.4.1 deployment metadata.

The included local-devnet addresses are rehearsal-only. Sepolia and Mainnet
require separately verified deployment releases.
