# Inbox

- Implement resolved Spark transfer policy: a claimed Spark PATH is a permanent, non-transferable award. Implement per-token ERC-5192 locking, emit `Locked(tokenId)` on Spark mint, reject every Spark secondary transfer including self-transfer, and keep regular PATH tokens fully ERC-721 transferable. Approvals must not bypass the Spark lock.
- Fix Spark invitation slot reservation: `allowSparker` must reserve a claimable slot instead of permitting overbooking. Claiming converts the pending slot to minted; expiry or issuer revocation returns it to the available reserved supply. Add permissionless expired-invitation cleanup and prevent duplicate reservation, claim, or release, including invitation refresh edge cases.
- Implement issuer-named Spark awards: the issuer supplies the agreed name while creating the Spark invitation, the invitee claim page displays the exact permanent public name before consent, and claiming stores it immutably with the Spark token. Use the name in the standard `tokenURI.name` while preserving the existing `Stage`, `THOUGHT`, `WILL`, and `AWA` traits and artwork; do not add `Spark` or `Name` traits. Keep Spark in the same OpenSea PATH collection, where `Transfer` indexes the token and ERC-5192 `Locked` disables trading. Add strict name validation/JSON escaping, stale-name protection at claim, runtime-size coverage, and gas measurements.
